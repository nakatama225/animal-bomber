# 葱ボンと延長戦

段階8の主題は**状態を型で表す**ことです。倒れたあとも試合に関わり続ける仕組み（葱ボン）と、
決着がつかないときの延長戦（サドンデス）を入れました。

## 何をする仕組みか

**葱ボン**：倒れたプレイヤーは、残り時間があれば盤面の外周へ回ります。外周の帯の上を
動きながら盤面へ葱を撃ち、盤面にいる相手に当てると入れ替わります。撃った側は当てた相手の
位置で盤面へ戻り、当たった側が外周へ回ります。残りが60秒を切ると外周は閉じ、外周にいた人は
退場します。

**延長戦**：時間切れの時点で2人以上残っているか、残っていた全員が同じ tick に倒れたとき、
1ラウンドに1回だけ延長戦に入ります。壊せるブロックを消し、加わる人をプレイヤー番号の順に左上・右上・左下・右下の隅へ移して
（始まった隅とは限りません。原型と同じ）、体力1個ぶん・爆弾と火力と靴を上限にします。

| 盤面にいる人数 | 判定 |
|---|---|
| 0 人 | 同じ tick に2人以上倒れていれば延長戦、でなければ引き分け |
| 1 人 | その人の勝ち。外周の葱ボンも、残り時間も待たない |
| 2 人以上 | 時間切れなら延長戦、延長戦のあとの時間切れなら引き分け |

## 状態を型で表す

原型はプレイヤーの状態を `'ALIVE'` `'NEGIBON'` `'OUT'` の文字列で持っていました。
この3つの文字列は、比較と代入を合わせて48か所に出てきます。外周の位置（`negiT`）と
撃つ間隔（`negiCool`）は、盤面にいるプレイヤーにも常に残っていました。

この版は、状態ごとに持つ値を分けた判別可能ユニオンにしました（`src/domain/state/Life.ts`）。

```ts
type Life =
  | { kind: 'alive' }
  | { kind: 'negibon'; along: number; readyAt: Tick }   // 外周上の位置と、次に撃てる時刻
  | { kind: 'out' };
```

| | 原型 | この版 |
|---|---|---|
| 外周の位置と撃つ間隔 | 全員が常に持つ | 外周にいる状態だけが持つ。盤面にいる人は型の上で持てない |
| 盤面にいるかの判定 | 文字列の比較をその場で書く | `isAlive(player)` の1つにまとめた |
| 状態を1つ足したとき | 文字列を検索して回る | 状態の要約（`hashWorld`）の `switch` が、書き忘れをコンパイルエラーにする |

⚠️ `Life` の値は**書き換えず、丸ごと差し替えます**。盤面にいる状態（`ALIVE`）と退場した状態
（`OUT`）は全員で1つを使い回しているので、中身を書き換えると全員の状態が変わります。
すべての項目を `readonly` にして、書き換えようとするとコンパイルが通らないようにしてあります。

## 葱ボンのための分岐を、盤面の処理に足していない

移動・爆弾・技・アイテム・被弾の System は、どれも最初に「盤面にいるか」（`isAlive`）で
プレイヤーを外しています。外周にいる人はそこで外れるので、これらの System には葱ボンのための
分岐を1つも足していません。

足したのは次の4つだけです。

| 足したもの | 役目 |
|---|---|
| `systems/NegibonSystem.ts` | 外周の移動と発射。残りが60秒を切ったら外周を閉じる |
| `negibon/LeekActor.ts` | 飛んでいる葱。狐火などと同じ自律物（`WorldActor`）として `ActorSystem` が進める |
| `negibon/lane.ts` | 外周の帯の上の位置と、盤面の座標の対応 |
| `mutations/negibon.ts` | 外周へ送る・入れ替える。倒れたときの `hurt()` に1つだけ分岐が入る |

技の System には1行だけ足しました。前の tick のうちに盤面を離れた人の技は、もう進めずに終えます。
進めると、盤面にいない人の技が1 tick ぶん働きます（拾った物が外周の人に渡る、など）。
外周の人に限らず、退場した人にも効く手当てです。

⭐ 葱が自律物で済んだのは、段階5で飛び道具を `WorldActor` という1つの形にしておいたためです。
`ActorSystem` は1行も変わっていません。

### 押した向きへ動く

外周の帯の上の位置は1つの数で表し、上辺の左端から時計回りに増えます。そのため下辺では左へ、
左辺では上へ増えます。キーを位置の増減に直結すると、下辺と左辺で操作が逆になります（原型で
実際に起きました）。押した向きを、その辺で位置が増える向きに重ねて、符号だけを採っています。

## 延長戦は、判定と準備を分けた

`RoundSystem.judge` は「続ける・延長戦に入る・終わる」の判定を返すだけで、盤面には手を出しません。
延長戦の準備は `mutations/suddenDeath.ts` が行い、`GameSession` が判定に応じて呼び分けます。

延長戦では盤面を作り直しません。柱の並びは種によらず決まっているので、壊せるブロックを消せば
作り直した盤面と同じになり、乱数も引きません。

盤面が同じもののまま全員が開始位置へ移るので、盤面の作り直しを合図にしている処理は、
延長戦にも同じ手当てが要ります。

| 処理 | 手当て |
|---|---|
| CPU の記憶 | `world.suddenDeath` が変わったら捨てる。捨てないと、移る前の場所で立てた道筋をたどる |
| 位置の補間（描画） | 飛び移ったプレイヤーは、1つ前の位置との間を埋めない。葱で戻ったときも同じ |
| 自律物の見た目 | 片付けで消えたのを「踏まれて消えた」と見なさない |
| 倒れたときの粒 | 位置は `playerDown` が運ぶものを使う。同じ tick に延長戦へ入ると、プレイヤーはもう開始位置にいる |

CPU の側は、外周での操縦と、盤面で飛んでくる葱をよける規則を足しました。よける規則は、
CPU の判断の並びに1行足しただけです（[02-CPU の判断](02-CPUの判断.md)）。

## 原型と変えたところ

| 原型 | この版 | 理由 |
|---|---|---|
| 葱ボンに落ちると、とくぎを持っている印だけ消え、回数は隠れて残る。次にチキンを拾うと戻る | 回数ごと 0 にする | 見た目どおりの振る舞いにする |
| 葱ボンに落ちると、盤面に置いた爆弾の数を 0 に戻す | 戻さない | 爆発したときに数え直す。0 にすると、まだ盤面にある爆弾のぶんだけ多く置ける |
| 延長戦に入ると、技のボタンを押した長さを 0 に戻す | 触らない | この版は離した瞬間に通常技を出す。0 に戻すと、長押しの途中が短い押しに化けて通常技が出る。原型は押した瞬間に出すので起きなかった |
| 葱で戻ったとき、技のボタンの状態を戻さない | 一度離すまで効かなくする | 外周にいる間は押した長さを数えないので、倒れたときの長さが残る。そのままだと戻った直後に通常技が出る |

## テストが見ていること

`tests/systems/negibon.test.ts` と `tests/systems/sudden-death.test.ts` にあります。
主なものは、それぞれ守っている1行を外すと失敗することを確かめました。

| 外したもの | 何が起きるか | 失敗するテスト |
|---|---|---|
| 押した向きを辺の向きに重ねる計算 | 下辺と左辺で操作が逆になる | どの辺でも、押した向きへ動く |
| 葱が外壁をすり抜ける判定 | 外周から撃った葱が、盤面に入る前に砕ける | 外壁をすり抜けて相手に当たると… ほか4本 |
| 無敵中の相手を通り抜ける判定 | 戻った直後の相手に撃ち返せて、入れ替わりが止まらない | 無敵中の相手は通り抜ける |
| 延長戦で押した長さに触らない約束 | 長押しを離した瞬間に通常技が出る | 長押しの途中で延長戦に入っても… |
| 延長戦は1回だけ、の条件 | 延長戦のあとの時間切れで、また延長戦に入る | 延長戦は1ラウンドに1回だけ… |
