# 葱ボンと延長戦

段階8の主題は**状態を型で表す**ことです。倒れたあとも試合に関わり続ける仕組み（葱ボン）と、
決着がつかないときの延長戦（サドンデス）を入れました。

## 何をする仕組みか

**葱ボン**：倒れたプレイヤーは、残り時間があれば盤面の外周へ回ります。外周の帯の上を
動きながら盤面へ葱を撃ち、盤面にいる相手に当てると入れ替わります。撃った側は当てた相手の
位置で盤面へ戻り、当たった側が外周へ回ります。残りが60秒以下になると外周は閉じ、外周にいたプレイヤーは
退場します。

外周を閉じるのは、その tick のぶんを引いた残りが60秒以下になった tick の**最後**です（被弾と、伸びている舌が
焼けたかを見たあと）。原型も update の最後（checkEnd の頭）で閉じるので、閉じる tick の中でも外周のプレイヤーは
動いて撃ち、飛んでいる葱は当たって入れ替わります。残りをその tick のぶんを引いたあとの値で見るのは、原型が
update の頭で残り時間を引いてから比べるためです。そのため 3:00 なら、残り60秒ちょうどの tick に倒れた
プレイヤーは外周へ回らずにその場で退場し、外周にほかにだれもいなければ「葱ボンは退場」の知らせも出ません。
7:00 だけは、原型が1/60秒を小数で引き続けた誤差で1 tick 遅く閉じます。この版は実数で数えた tick のままです。

**延長戦**：時間切れの時点で2人以上残っているか、残っていた全員が同じ tick に倒れたとき、
1ラウンドに1回だけ延長戦に入ります。壊せるブロックを消し、加わる人をプレイヤー番号の順に左上・右上・左下・右下の隅へ移して
（始まった隅とは限りません。原型と同じ）、体力1個ぶん・爆弾と火力と靴を上限にします。

| 盤面にいる人数 | 判定 |
|---|---|
| 0 人 | 同じ tick に2人以上倒れていれば延長戦、でなければ引き分け |
| 1 人 | その人の勝ち。外周の葱ボンも、残り時間も待たない |
| 2 人以上 | 時間切れなら延長戦、延長戦のあとの時間切れなら引き分け |

## 状態を型で表す

原型はプレイヤーの状態を `'ALIVE'` `'NEGIBON'` `'OUT'` の文字列で持っていました。
この3つの文字列は、比較と代入を合わせて48か所に出てきます。外周の位置（`negiT`）と
撃つ間隔（`negiCool`）は、盤面にいるプレイヤーにも常に残っていました。

この版は、状態ごとに持つ値を分けた判別可能ユニオンにしました（`src/domain/state/Life.ts`）。

```ts
type Life =
  | { kind: 'alive' }
  | { kind: 'negibon'; along: number; readyAt: Tick }   // 外周上の位置と、次に撃てる時刻
  | { kind: 'out' };
```

| | 原型 | この版 |
|---|---|---|
| 外周の位置と撃つ間隔 | 全員が常に持つ | 外周にいる状態だけが持つ。盤面にいる人は型の上で持てない |
| 盤面にいるかの判定 | 文字列の比較をその場で書く | `isAlive(player)` の1つにまとめた |
| 状態を1つ足したとき | 文字列を検索して回る | 状態の要約（`hashWorld`）の `switch` が、書き忘れをコンパイルエラーにする |

⚠️ `Life` の値は**書き換えず、丸ごと差し替えます**。盤面にいる状態（`ALIVE`）と退場した状態
（`OUT`）は全員で1つを使い回しているので、中身を書き換えると全員の状態が変わります。
すべての項目を `readonly` にして、書き換えようとするとコンパイルが通らないようにしてあります。

## 葱ボンのための分岐を、盤面の処理に足していない

移動・爆弾・技・アイテム・被弾の System は、どれも最初に「盤面にいるか」（`isAlive`）で
プレイヤーを外しています。外周にいる人はそこで外れるので、これらの System には葱ボンのための
分岐を1つも足していません。

足したのは次の4つだけです。

| 足したもの | 役目 |
|---|---|
| `systems/NegibonSystem.ts` | 外周の移動と発射。残りが60秒以下になったら外周を閉じる |
| `negibon/LeekActor.ts` | 飛んでいる葱。狐火などと同じ自律物（`WorldActor`）として `ActorSystem` が進める |
| `negibon/lane.ts` | 外周の帯の上の位置と、盤面の座標の対応 |
| `mutations/negibon.ts` | 外周へ送る・入れ替える。倒れたときの `hurt()` に1つだけ分岐が入る |

技の System には1行だけ足しました。前の tick のうちに盤面を離れた人の技は、もう進めずに終えます。
進めると、盤面にいない人の技が1 tick ぶん働きます（拾った物が外周の人に渡る、など）。
外周の人に限らず、退場した人にも効く手当てです。

ただし、盤面を離れても残す性質（`ActiveAction.staysOffBoard`）を持つ振る舞いは、終えずにその場で止めておき、
爆風に触れたかだけを見続けます。いまこの性質を持つのは舌だけです。原型は倒れても舌を消さず、舌を進めるのは
盤面にいるプレイヤーだけで、焼けたかの確かめは状態を問わず全員について行うためです。外周にいる間（退場した
あとも）止まった舌の上へ爆風が来ると焼けて、そのラウンドの舌が短くなり、泣きます。葱で盤面へ戻るときに、
止まった舌も泣く状態も消えます（短くなった長さは残る）。描くのは盤面にいるプレイヤーだけなので、止まった舌は
見えません（原型も同じ）。

⚠️ 盤面の処理を `isAlive` で外す決まりに「盤面を離れても残す振る舞い」の分岐を足したのは、技の System の
2か所（振る舞いを進める所と、焼けたかを見る所）だけです。ほかの System には足していません。

⭐ 葱が自律物で済んだのは、段階5で飛び道具を `WorldActor` という1つの形にしておいたためです。
葱を足したとき、`ActorSystem` は1行も変わりませんでした。

あとから、同じ tick の葱を新しく撃ったものから進めるようにしました（原型の updateNegis は葱の配列を後ろから
回す）。別々の葱ボンが撃った葱が同じ tick に同じ相手に届くと、あとに撃った葱の持ち主が戻ります。`ActorSystem` には
葱の名前を書かず、自律物の性質 `newestFirst`（同じ順番のものどうしを新しいものから進める）を1つ足して、
その性質で並べています。撒く本体と跳ねる爆弾にも、同じ性質を付けています（原型の updatePoroporos L2756 と
updateSlimes L2949 も配列を後ろから回す）。

### 押した向きへ動く

外周の帯の上の位置は1つの数で表し、上辺の左端から時計回りに増えます。そのため下辺では左へ、
左辺では上へ増えます。キーを位置の増減に直結すると、下辺と左辺で操作が逆になります（原型で
実際に起きました）。押した向きを、その辺で位置が増える向きに重ねて、符号だけを採っています。

### 葱を撃つボタン

外周では、爆弾のボタンか技のボタンを押した瞬間に葱を撃ちます。押した瞬間の取り方は原型と違い、盤面で爆弾を
置くときと技を出すときも同じ違いがあります。原型はキーが押し下がるたび（keydown）に、それを次のフレームまで
ためておくので、同じ役のキーを2つ重ねて押したときや、1フレームより短く押して離したときにも撃ちます。この版は
tick ごとに、押しているかを前の tick と比べるだけなので、どちらでも撃ちません。入力は tick ごとにどのボタンを
押しているかだけを持ち（操作の記録と通信対戦も同じ形）、tick の間に押して離したことを表せないためです。

## 延長戦は、判定と準備を分けた

`RoundSystem.judge` は「続ける・延長戦に入る・終わる」の判定を返すだけで、盤面には手を出しません。
延長戦の準備は `mutations/suddenDeath.ts` が行い、`GameSession` が判定に応じて呼び分けます。

延長戦では盤面を作り直しません。柱の並びは種によらず決まっているので、壊せるブロックを消せば
作り直した盤面と同じになり、乱数も引きません。

盤面が同じもののまま全員が開始位置へ移るので、盤面の作り直しを合図にしている処理は、
延長戦にも同じ手当てが要ります。

| 処理 | 手当て |
|---|---|
| 位置の補間（描画） | 飛び移ったプレイヤーは、1つ前の位置との間を埋めない。葱で戻ったときも同じ |
| 自律物の見た目 | 片付けで消えたのを「踏まれて消えた」と見なさない |
| 倒れたときの粒 | 位置は `playerDown` が運ぶものを使う。同じ tick に延長戦へ入ると、プレイヤーはもう開始位置にいる |

CPU の記憶は、延長戦に入っても捨てません。原型の enterSuddenDeath も CPU の記憶に触らないので、開始位置へ
移ったあとも、次に考え直すまで（よわいで最大 0.73 秒）は移る前の経路の先のマスへ歩きます。葱で戻ったときも
同じです。原型が CPU の記憶を作り直すのは、ラウンドの始まりだけです。最後に傷を付けた相手（`lastHitBy`）も、
延長戦と葱で戻るときに戻しません（原型も戻さない。試合の中で読む所は無く、状態の要約だけに入る）。

CPU の側は、外周での操縦と、盤面で飛んでくる葱をよける規則を足しました。よける規則は、
CPU の判断の並びに1行足しただけです（[02-CPU の判断](02-CPUの判断.md)）。

## 外周へ回るときと戻るときに持ち越すもの

外周へ回るときと戻るときのルールは原型と同じです。数え方は、原型が 1/60 秒を小数で引き続けたために出る
1フレームの差（7:00 で外周を閉じる tick など）を、実数で数えた tick のままにしています。

| | 外周へ回るとき | 葱で戻るとき |
|---|---|---|
| かかっている状態 | 消す | 消す（外周で舌が焼けて付いた泣く状態も） |
| 乗っ取り中の振る舞い | 舌だけ止めて残す（ほかは次の tick に外す） | 消す（後始末は呼ばない） |
| 火力・爆弾の上限・靴 | 持ち越す | 持ち越す |
| 置いている爆弾の数 | 0 に戻す | 0 に戻す |
| とくぎ | 持っている印だけ外す（回数は残る） | 触らない |
| 体力 | ― | 1個ぶん（半分の単位で 2） |

火力などを持ち越すのは、戻るたびに初期値へ戻すと、終盤に誰も強くならず決着がつかないためです（原型の注記）。
置いている爆弾の数を 0 に戻しても、戻ったあとに多く置けることはありません。外周へ回ってから最初に撃てるまで
3.5 秒かかり、導火線（2.4 秒）より長いので、戻る時点では、倒れる前に置いた爆弾はもう爆発しています。外周に
いる間に爆発しても、数を減らすのは 0 で止めます。

とくぎは原型と同じく、持っている印（`hasSpecial`。原型の chicken）と回数（`specialCharges`。原型の
chickenCharges）を別に持ちます。外周へ回ると印だけが外れ、回数は見えず使えないまま残ります。同じラウンドの
うちに盤面へ戻ってチキンを拾うと、印が戻り、残っていた回数に足されます。延長戦とラウンドの始まりでは両方を
戻します。とくぎが出せるか、CPU がとくぎを使うか（かえるが舌を伸ばすかも）、足元の絵文字・名札・長押しのゲージに
出すかは、どれも印で見ます。原型もすべて chicken で見るので、残った回数だけでは何も変わりません。

技のボタンは原型と同じです。延長戦に入ると押した長さを数え直し（押したままなら、しきい値ぶん押し続けると
とくぎがもう一度出る）、葱で戻ったときは倒れたときの長さのまま数え続けます。どちらも押した瞬間には
なりません。

## テストが見ていること

`tests/systems/negibon.test.ts` と `tests/systems/sudden-death.test.ts` にあります。
主なものは、それぞれ守っている1行を外すと失敗することを確かめました。

| 外したもの | 何が起きるか | 失敗するテスト |
|---|---|---|
| 押した向きを辺の向きに重ねる計算 | 下辺と左辺で操作が逆になる | どの辺でも、押した向きへ動く |
| 葱が外壁をすり抜ける判定 | 外周から撃った葱が、盤面に入る前に砕ける | 外壁をすり抜けて相手に当たると… ほか4本 |
| 無敵中の相手を通り抜ける判定 | 戻った直後の相手に撃ち返せて、入れ替わりが止まらない | 無敵中の相手は通り抜ける |
| 延長戦で押した長さを数え直す行 | 押したまま延長戦に入ると、とくぎがもう一度出ない | 長押しの途中で延長戦に入ると… |
| 延長戦は1回だけ、の条件 | 延長戦のあとの時間切れで、また延長戦に入る | 延長戦は1ラウンドに1回だけ… |
