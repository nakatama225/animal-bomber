# 歩き方

原型は「動くもの」を最短で作りました。この版は**同じゲームを、境界を引き直して
作り直したもの**です。移植ではありません。

境界を引くと何が起きるかは、あとの段階になって現れます。通信対戦を作る段になって、
すでに書いてある `IntentSource` という1つの窓口に、ネットワークから届いた操作を
流し込むだけで済む。CPU の強さを1万試合で測る段になって、画面を描く部分を
差し替えるだけで済む。

**設計とは、未来の作業量を先に減らしておくことです。** この docs は、
どの判断がどの作業を減らしたのかを、順を追って残すものです。

---

## 読む順序

| | 内容 |
|---|---|
| [01-層とは何か](01-層とは何か.md) | 7つの層と、依存を一方向に保つ仕組み |
| 02-決定性とは何か | 同じ入力で同じ結果になることと、そこから無料で手に入る3つのもの |
| 03-使ったパターンと使わなかったパターン | 採用した7つと、却下した8つの理由 |

コードから読むなら `src/domain/` から始めてください。ここには
ブラウザも実時間も通信も出てきません。ゲームのルールだけがあります。

## 段階ごとの主題

実装は段階に分けて進めています。各段階には**その段階で身につく判断が1つ**あり、
それが次の段階の作業を減らします。

| 段階 | 動くもの | その段階の主題 |
|---|---|---|
| 0 | 骨組み | 境界を、規約ではなく検査で守る |
| 1 | 1人が歩く・直前を再生できる | 固定間隔の時間と、注入された乱数 |
| 2 | 爆弾・誘爆・ブロック破壊 | System への分業。`step()` が順序の一覧になる |
| 3 | アイテム・被弾 | 起きたイベントを戻り値で返す（音と画面を呼ばない） |
| 4 | 2人で遊べる | 操作の出どころを1つの窓口にまとめる |
| 5 | 5匹の動物 | 拡張に開いた形（Strategy）。ぞうの突進で正しさを判定する |
| 6 | CPU | 判断を順序つきの独立した規則に分ける |
| 7 | 絵と音 | 移植でよい所と、設計し直す所の区別 |
| 8 | 葱ボン | 状態を型で表す |
| 9 | 通信対戦 | ロックステップ。窓口を差し替えるだけで済むことの確認 |
| 10 | タイトル・設定 | いちばん面白くないので最後 |

## この実装での約束

3つあります。いずれも**人が気をつけて守る形にしていません**。破ると検査が落ちます。

### ルールの層はブラウザを知らない

`src/domain/` には `document` も `window` も `canvas` も出てきません。
書くと型エラーになります（`tsconfig.domain.json` から DOM の型定義を外してある）。

### ルールの層は実時間と乱数を自前で取らない

`Math.random()` も `Date.now()` も使いません。書くと lint が落ちます。
乱数は引数として受け取り、時間は tick の回数で数えます。

### 依存は逆流しない

下の層が上の層を import すると、依存の検査が落ちます。
ルール表は [`.dependency-cruiser.cjs`](../.dependency-cruiser.cjs) にそのまま書いてあります。

---

## 検査が効いていることを、どう確かめているか

設定を書いただけでは、それが効いているかは分かりません。設定の書き方を
間違えていても、違反が無ければ検査は緑のまま通ります。**緑のまま通る検査は
何も守っていません。**

そのため [`tests/boundary/guards.test.ts`](../tests/boundary/guards.test.ts) では、
わざと違反したファイルを置いて**検査が落ちること**を確かめ、そのうえで片付けています。

```
✓ 違反が無ければ、3つの検査はいずれも通る
✓ ルールの層でブラウザ API を使うと型検査が落ちる
✓ ルールの層で Math.random を呼ぶと lint が落ちる
✓ ルールの層から上の層を import すると依存の検査が落ちる
```

1本目があるのは、「壊したから落ちた」のか「もともと落ちていた」のかを
区別するためです。壊す前が通っていることを先に確かめないと、逆向きの確認は
何も検証しません。

## 動かし方

```sh
npm install
npm run dev      # 開発サーバ
npm run verify   # 型検査 + 層の検査 + lint + テスト
npm run graph    # docs/layers.svg に層の図を出す（Graphviz が要る）
```
