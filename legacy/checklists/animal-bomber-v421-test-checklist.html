どうぶつボンバー v4.2.1 実機テスト

ロビーでルールを決められるようにした（v4.2.0）のと、潜んでいた不具合5件を直した（v4.2.1）の確認。 A → B → C の順にやる（A が通らないうちに LAN へ行くと、どこが悪いのか分からなくなる）。 結果は一番下のテキスト欄に自動でたまるので、コピーして開発側に貼る。途中で閉じても入力は残る。

言葉の確認（呼び方がズレていたので揃える）
コントローラー作者の STK-7043。コード上は「パッド」とも呼ぶが同じもの。コードの中が PAD / Pad:A と書いてあるせい
リザルト画面ラウンドが終わったとき画面の真ん中に出るカード。「ラウンド3　うさぎの かち」みたいに出て、下に「つぎのラウンド ▶」ボタンがある（優勝が決まった時は「もういっかい」）
リザルト画面を進めるその「つぎのラウンド ▶」を押すこと。マウス・キーボードの Space / Enter・コントローラーの A、どれでもできる。コード上「バナーを送る」と呼んでいるのはこれ
技ボタンコントローラーだと B・X・Y・L1。ポンと押す＝通常技、0.5秒 押し続ける＝とくぎ🍗
白い枠コントローラー（か矢印キー）でいまどこを指しているかを示す枠。選んだものに付く黄色い印とは別物
ロビーLAN対戦で「たてる／さんかする」のあとに出る画面。ここで人数・キャラ・たいりょく・何勝先取・じかん・サドンデスを決める（後半4つは v4.2.0 で追加）
枠1P / 2P / 3P / 4P の4つ。人間でも CPU でも「枠」と呼ぶ
ホスト / ゲストホスト＝.app（サーバ）を立てる方＝作者の Mac。ゲスト＝URL を開くだけの方＝家族の Mac
