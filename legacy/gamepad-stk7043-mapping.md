## ⭐ 設計に効く事実

- **`mapping: "standard"` が出た。** ブラウザが Xbox 標準配列に正規化している。
  → **番号の当て推量が不要**。この製品専用の対応表を書かずに済み、PS/Xbox 純正など
  他の `standard` なパッドも同じコードで動く。非標準（`mapping:""`）だったら
  製品ごとの対応表とその保守が発生していた
- **十字キーがボタン12〜15（デジタル）で来た。** 軸ではない。
  → 既存の `hold()`/`edge()` とそのまま噛み合う。アナログ軸ならしきい値と
  デッドゾーンの設計が要ったが、それが不要
- **`index` で複数台を識別できる。** 1台の Mac に2個挿して2人、も成立する
  （LAN対戦とは独立した別軸の拡張）

## ⛔ 罠（実機で踏んだもの）

| 罠 | 実態 |
|---|---|
| **USB有線で繋ぐと振動が止まらなくなる** | Switch 用製品なので、有線時に想定している相手（Switch のドック）と Mac の応答が違い、接続確立に失敗して振動し続ける。**ケーブルを抜くまで止まらない**（給電されている間は電源も落とせない） |
| 有線中の HOME 長押しは電源オフではない | X入力 ⇄ D入力の**モード切替**に割り当たっている。長押ししても電源は落ちない |
| **Bluetooth の Xbox モードで繋ぐこと** | `✛（十字キー）+ HOME` 同時押しで電源ON → Mac の Bluetooth 設定に `Xbox Wireless Controller` として出る → LED1 点灯で成功。HOME 単独で電源を入れると Switch を探すモードで起動して振動する |
| **HOME ボタンは Gamepad API に届かない** | macOS がシステム側で握っている（Game Center のオーバーレイ）。システム設定でショートカットを切っても、アプリが開かなくなるだけでブラウザには渡らない。**→ HOME に機能を割り当てない** |

## 接続手順（家族に渡す用）

```
1. ✛（十字キー）+ HOME を同時押しして電源ON  → LED1 と LED4 が点滅
2. Mac の システム設定 → Bluetooth
3. 「Xbox Wireless Controller」を選んで接続
4. LED1 だけが点灯したら成功
```

⛔ USB ケーブルでは繋がない（上の罠）。

## ⭐ 効かないときに最初に見るところ（2026-09-20 実測）

**「コントローラーが動かない」の第一容疑は Bluetooth の切断。ゲームを疑う前にここ。**

2026-09-20、v4.0.0 の実機テストの初日に実際に踏んだ。前日は繋がっていたのに
翌日「コントローラーが見つからない」になり、ゲーム側のバグを疑って
ポーリング処理を読みに行った。原因は OS レベルで切れていただけだった。

### 状態の見かた（目視より確実）

```sh
system_profiler SPBluetoothDataType | grep -A8 "Connected:"
```

- `Connected:` の下に `Xbox Wireless Controller` があれば OS とは繋がっている
  （`Services: 0x800020 < HID ACL >` まで出ていればブラウザからも見えるはず）
- `Not Connected:` の下にいたら切れている。`RSSI` の値が出ていても切断は切断
  （電波が届いている＝繋がっている、ではない）

### 直しかた（軽い順）

| | やること | 効く理由 |
|---|---|---|
| 1 | **HOME 長押し** | **一度 Xbox モードでペアリング済みなら、これだけで Xbox モードで復帰する**（2026-09-20 実測）。初回のペアリングは上の「接続手順」のとおり ✛+HOME が要る |
| 2 | システム設定 → Bluetooth → `Xbox Wireless Controller` の「接続」 | OS 側から繋ぎに行く |
| 3 | ペアリングし直す（デバイスを削除 → ✛+HOME） | 最後の手段 |

⭐ **HOME が復帰に使えるのは、HOME を macOS が握っているから**（上の罠の表を見る）。
Gamepad API に届かないのと同じ理由で、OS レベルの電源・接続には効く。
「割り当てられないボタン」だが「無用のボタン」ではない。

### 切り分けの順番

1. 上の `system_profiler` で OS と繋がっているか
2. 繋がっていたら `gamepad-probe.html` を開いて**何かボタンを1つ押す**
   （ブラウザは最初の入力があるまでパッドを見せない仕様。押さないと
   「コントローラーが見つからない」と出るが、それは切断とは限らない）
3. probe でボタン一覧が出たらブラウザまでは届いている。そこで初めてゲーム側を疑う
